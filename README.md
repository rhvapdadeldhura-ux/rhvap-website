# R-HVAP Application — Organized Reference Build

## Structure
- `index.html` — home/landing page
- `notice.html` — notice PDF page
- `form.html` — application-form PDF page
- `apply.html` — online application form markup
- `assets/css/style.css` — all shared styles
- `assets/js/app.js` — form behavior, validation, uploads, draft, language, submission
- `assets/js/config.js` — public configuration only (Apps Script Web App URL)
- `assets/emblem.png` — government emblem
- `assets/fonts/Kalimati.ttf` — local Nepali font
- `assets/notice.pdf` — notice document
- `assets/form.pdf` — original application PDF
